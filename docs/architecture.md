# 员工画像系统架构规划

## 1. 总体目标

构建一个可扩展的员工画像平台，为 HRBP、直属经理和管理层提供：

- 人才盘点（高潜、核心、风险）
- 发展建议（培训、轮岗、晋升）
- 组织洞察（部门能力分布、流失风险）

## 2. 分层设计

### 数据层

- 主数据：员工主档、组织架构、岗位序列
- 行为数据：任务协作、学习记录、出勤活跃度
- 绩效数据：季度/半年度绩效

### 计算层

- 指标标准化（0-100）
- 规则引擎（标签判断）
- 可选模型层（流失预测、潜力预测）

### 服务层

- 画像服务：对外提供个人画像与组织画像 API
- 解释服务：返回“标签由哪些指标触发”
- 推荐服务：输出培养建议

### 展示层

- 员工画像卡片
- 团队九宫格
- 部门热力图

## 3. 关键实体

- `Employee`：员工基础信息
- `SkillScores`：能力维度分
- `EmployeeProfile`：画像结果（能力、绩效、稳定性、潜力标签）

## 4. 演进路线

1. M1（当前）：规则驱动画像 + 列表查询
2. M2：接入数据库与权限控制（RBAC）
3. M3：引入机器学习评分与可解释分析
4. M4：全量组织视图与预警机制
